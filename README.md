# lbarker1996.github.io

### Welcome to My Portfolio!
This repo includes the contents (and build files) for my portfolio website. 
The content is largely markdown files that have been built into a static website using [zensical](https://github.com/zensical/zensical). 
The website is "hosted" using [GitHub Pages](https://docs.github.com/en/pages), accessible via the domain [levimbarker.com](https://levimbarker.com/).
